# Tabs

同じ場所で、表示する中身を切り替える。選ばれているタブは下線で分かり、読み上げでも「選択中」と伝わる。`Tabs`・`TabsList`・`TabsTrigger`・`TabsContent` に分かれ、件数は `TabsCount` で添える。

<Canvas of={TabsStories.Default} />

## 使う場面

- 同じ画面の同じ場所で、関連する別の中身を切り替えて見せるとき（概要と詳細、未対応と完了）。
- 切り替えても画面の移動にならず、前後の状態（入力中の値など）が保たれてよいとき。
- 件数を添えて、各タブの中に何件あるかを先に伝えたいとき（`TabsCount`）。

## 使わない場面

- 別の画面へ移るナビゲーションには使わない。リンク（`<a>`）やメニューにする。
- 手順を順番に進めるもの（ステップ）には使わない。
- タブが多すぎて 1 列に収まらないときは使わない。項目を絞るか、別の見せ方にする。
- ボタンの組で値を 1 つ選ぶだけの小さな切り替えには使わない（別の部品で決める）。

## 書き方の決まり

- `TabsList` には `aria-label` を付け、何の切り替えかを読み上げに伝える。
- 件数は `TabsTrigger` の中に置く。読み上げではタブの名前に含まれる（「未対応 3」）。
- 押せないタブは `disabled` にする。矢印キーでは止まり、読み上げで「利用不可」と伝わるが、選ばれない。
