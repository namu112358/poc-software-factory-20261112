# このアプリで良くしたいこと

Issue を作るときの拠り所です。Issue は、下の「良くしたいこと」のどれかにつなげ、本文の冒頭に「どの困りごとを、どう良くするか」を 1 行書きます。

## だれが何のために使うか

数人のチーム（今は佐藤・鈴木・田中）が、日々の作業をタスクとして持ち、だれが何をいつまでにやるかを共有するためのアプリです。

- **メンバー**: 自分の担当のタスクを進め、間に合わなければ期限の延長を申請する。
- **取りまとめる人**: チーム全体の進み具合を見て、担当を割り振り直し、延長の申請を承認する。
- 社内の連携スクリプトが API でタスクを読み書きすることもある。

## 次の 1 か月で良くしたいこと

1. **期限に遅れそうなタスクに、早く気づいて手を打てる**
   期限切れや期限間近のタスク、承認を待っている延長の申請が、探さなくても目に入る。
2. **担当の割り振りや引き継ぎを、安全に、手早くできる**
   異動や休みのときに、複数のタスクの担当をまとめて替えられ、だれがいつ替えたかを後から確かめられる。
3. **目当てのタスクに、すぐたどり着ける**
   タスクが増えても、キーワード・担当者・タグ・期限で絞り込み、並べ替えて、探す時間を減らす。表記の揺れも減らす。
4. **同時に触っても、間違えて操作しても、データを失わない**
   2 人が同じタスクを直しても上書きし合わない。消す前に確かめ、消さずに隠す手段（アーカイブ）もある。
5. **自分のアカウントを、自分で守れる**
   身に覚えのないログインに気づける。（パスワードの変更と、ほかの端末のログインを切る操作は、すでにできる）

## 使ってみて見つかった、まだ解決していないこと

2026-11-12 に、使う人の立場でアプリを動かして確かめた。メンバー（#411）、取りまとめる人（#421）、連携スクリプト（#426。キーワード検索のずれは #429）の回で見つけた困りごとは直した。結果は `docs/results/` にある。

次は、2026-11-12 22:45 に、休みに入るメンバー（鈴木）・引き継ぐ取りまとめる人（田中）・引き継がれるメンバー（佐藤）の立場で使って見つけたこと。どちらも Issue にした（Epic #435）。直ったかどうかは、各 Issue を見る。

- 2・3 について（#436。PR #439 で直した）: あるメンバーの担当をすべて引き継いだあと、そのメンバーで絞り込むと、全員のタスクが出た。
  - 画面・CSV・API のどれも同じ。担当者の絞り込みの選択肢からも、そのメンバーが消える。
  - 「鈴木の残りのタスクは無いか」を確かめたい場面で、全件が「鈴木の担当」のように見える。そこからまとめて担当を替えると、ほかの人のタスクまで替えてしまうおそれがある。
- 1・2 について（#437）: 新しいタスクを作る画面では、担当者の選択肢に、休み中であることと、その人が持っているタスクの数が出ない。
  - 担当の変更とまとめての変更の画面には出る。
  - そのため、休み中の人に、気づかずに新しいタスクを割り当てられる。

次のことは、使って確かめて、困りごとにしなかった。

- だれがいつ担当を替えたかは、タスクの詳細の「担当者の履歴」に残る。
- 新しく担当になったタスクは、次のログインのときに知らされる。
- ほかの端末のログインは「ログイン中の端末」に出て、その端末だけを切れる。

次は、2026-11-12 23:52 に、佐藤・鈴木・田中の 3 人で同時に使い、「4. データを失わない」を確かめて見つけたこと。どちらも Issue にした（Epic #444）。どちらも、前の Issue（#374・#385）で対象外とした部分だった。

- 4 について（#445）: コメントを消すと、二度と戻らない。
  - タスクの削除は、30 日のあいだ、コメント・タグ・延長の申請ごと戻せる。コメント 1 件の削除だけが戻せない。
  - 編集の前の本文も残らない。これは別の Issue（#447、`status:ready` なし）として残した。
- 4 について（#446）: 2 人が同じタスクの別々の項目を直し、後から保存した人が断られると、自分の入力をすべて入れ直すことになる。
  - 「今の値で編集し直す」を押すと、相手が変えていない項目の自分の入力も消える。例えば、相手がメモを、自分が期限を直した場合。
  - 消えた入力は、相手が変えた項目の表にも出ない。

次のことは、使って確かめて、困りごとにしなかった。

- 同時に編集すると、後からの保存は上書きせずに断られる。相手が変えた項目は表で見られる。まとめての変更と編集が重なっても断られる。
- タスクを削除して戻すと、コメント・タグ・承認待ちの延長の申請が元どおりに戻る。削除している間は、承認待ちの一覧に出ない。
- アーカイブしたタスクは、期限切れの一覧・集計・ボードに出ない。アーカイブは「やめたタスク」の扱いで、#259 で決めたとおり。詳細から戻せる。

## Issue にしないもの

- 良くしたいことのどれにもつながらない変更。
- 使う人にとって意味のある変化にならない、小さな飾りだけの変更（例: 件数を 1 つ表示するだけ）。必要なら、意味のある変更の一部として扱う。
