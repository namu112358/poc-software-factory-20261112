# [SF-D][Epic] 外出先でスマートフォンから、タスクを読んで操作できるようにする（#484）の結果

連続運転 D（2026-11-13、計画は #122）のうち、外出先でスマートフォンから使うメンバーの立場で使って見つけた困りごとを直した Epic の結果です。使う人の立場で動かす回の 8 回目で、7 回目（#477）と並べて回しました（台帳 E16）。

## 確かめたいこと

- スマートフォンの画面の大きさで見つけた困りごと（`docs/product.md`、PR #506）から作った Issue が、受入条件どおりに直るか。
- これまでの回はパソコンの画面で使っていた。スマートフォンでしか出ない困りごとがあるか。

## 見つけ方

2026-11-13 02:18 に、main（34eff8d）を `npm start` で起動し、タスクを 31 件にした。Playwright の iPhone 13 の画面の大きさ（390×664）と横向き（844×390）で、次を試し、高さ・押せる範囲・文字の大きさ・操作の回数を記録した。

- ログイン
- ヘッダー
- タスク一覧
- ステータスの変更
- タスクの作成
- コメント
- 延長の申請
- ボード・メンバーの一覧・期限切れの一覧

操作と記録はサブエージェント（sonnet）に任せ、困りごとの見立ては D がした。

困りごとが 2 つ見つかった。

- 縦向きのタスク一覧で、10 列の表が 342px に詰まり、題名が 1 文字ずつ折り返した。
  - 1 件の高さは平均 155px で、31 件で 4,846px になった。
- 押せる場所が小さかった。
  - 一覧で押せる場所 88 個のうち 60 個が 44px 未満だった（行のチェックボックスは 13px）。

次のことは、困りごとにしなかった。

- 横向きでは、題名は 1 行で読めた。
- どの画面も、文字は 12px 以上だった。
- 編集の保存やまとめての変更の欄が画面の外に出ることは、2 つを直せば一緒に直る。

確かめ直しの中身:

1. #485（一覧の並び。#486 の前、03:05）
   - 10 文字の題名は 1 行に収まった。ステータス・期限の文字は縦に割れず、各項目に「ステータス：」などの項目名が付いた。
   - 読み上げでも、各値に項目名が付いた。
   - まとめての変更も使えた。
   - 幅 1,280px は 10 列の表のままだった。
   - ただ、1 件の高さは 115px で、受入条件（100px 以内）に届かなかった。#486 で題名のリンクが 44px になったため。#502 で直した。
2. #486（押せる範囲）
   - 一覧で押せる場所は、93 個のうち 44px 未満が 6 個になった（直す前は 88 個中 60 個）。残ったのは、キーボードで使うときだけ出る「本文へ移動」と、本体は 44px ある絞り込みのチェックボックスのラベル。
   - 入力欄とボタンの文字は 16px になった。
   - 幅 1,280px の見た目は変わらなかった。フォーカスの枠と「本文へ移動」も崩れなかった。
   - ただ、文字が 16px になったことで、メモの入力欄が広がり、詳細と新しいタスクの画面が横にはみ出した（434px）。#502 で直した。
3. #502（2 つが合わさった画面。03:25）
   - どの画面も横にはみ出さなくなった（390 / 390）。
   - 一覧の 1 件の高さは 95px になった（31 件で 2,945px。直す前は 4,846px）。
   - 「作成」ボタンを指で押せた。
   - 押せる範囲（44px）・文字（16px）・幅 1,280px の見た目・読み上げの項目名は保たれた。

時刻はすべて UTC。ready・着手の時刻は GitHub のラベルのイベント、マージの時刻は PR のマージの時刻による。

## 分かったこと

- 同じ画面を変える 2 つの Issue を、別々の受入条件で直すと、合わさった画面で抜けが出た（台帳 E15 の例）。
  - #485 は一覧の行の高さを、#486 は押せる範囲と文字の大きさを直した。
  - それぞれのレビューは ok だったが、合わさると、行の高さが受入条件を超え、別の画面が横にはみ出した。
  - 気づいたのは、マージ後に D が全体を動かして確かめたとき。
- キーボード・読み上げの回（B、Epic #451）で入れた決まりを、Issue の補足に書いて渡したら、どの直しでも崩れなかった。
  - 決まり: フォーカスの枠、本文へ移動、読み上げの項目名。
- 3 件とも、ready から着手までは 2 分以内（待ちを除く）で、人の手なしに動いた。

## 残したこと

- ログインの画面に、favicon の 404 がコンソールに出る（使う人には見えない）。
- 実機の iPhone の Safari では確かめていない（Playwright の Chromium で、画面の大きさだけをまねた）。
